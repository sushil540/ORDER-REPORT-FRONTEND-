# Report Generation Frontend

A modern web application built with React and Tailwind CSS for generating and managing reports. This frontend application provides a user-friendly interface for creating, viewing, and managing various types of reports.

## Features

- **Modern UI**: Built with React and styled using Tailwind CSS for a responsive and beautiful user interface
- **Form Handling**: Advanced form management using React Hook Form and Formik with Yup validation
- **PDF Generation**: Integration with PDF.js for report generation and viewing
- **Authentication**: Protected routes and secure user authentication
- **API Integration**: Seamless backend communication using Axios

## Tech Stack

- **Frontend Framework**: React 19
- **Styling**: Tailwind CSS
- **Form Management**: React Hook Form, Formik, and Yup
- **Routing**: React Router DOM
- **HTTP Client**: Axios
- **UI Components**: Headless UI, Tailwind React
- **PDF Handling**: PDF.js
- **Build Tool**: Vite

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

- `/src/components`: Reusable UI components
- `/src/pages`: Application pages and views
- `/src/assets`: Static assets and resources
- `/src/config`: Configuration files
- `/src/api.js`: API integration and services

## Development

- Run the development server: `npm run dev`
- Lint the code: `npm run lint`
- Preview production build: `npm run preview`
